# Warm Extract

A Claude Code skill for the moment right after a real conversation. Type
/warm-extract, then brain-dump everything you remember, messy, in any order.
It files every quote word for word, hands back the one cell for your
Outreach Sheet, gives you two or three ways you could serve that person,
names your starting point, and grows `squad/draft-offer.md`: your offer,
forming call by call. It never sends and never prices.

## Install (one paste)

Open Claude Code and say:

```
Install this skill: https://github.com/AI-ChrisLee/warm-extract. Clone the whole folder into .claude/skills as warm-extract, without the .git folder.
```

Then type / and look for it; it normally shows up right away, and a new
session brings it up if not.

## Run it

```
/warm-extract
ok so marcus. redoes the same 3 fixes every job, never charged. clients text
at 11pm he loses half by morning. quotes take him 2 nights. said if someone
handled the revision emails he'd pay tomorrow...
```

That is the whole move. Built and used by
[AI Chris Lee](https://www.youtube.com/@aichrislee). Part of the Execution
Squad system; skills update every season, so install fresh.
